# Validação

Casos e provas das rodadas da SV (método em `sessoes/SV-validacao.md`).

- `V<n>.md`: os casos da rodada (um por linha: id, regra ou risco, o que fazer, o que deve acontecer, onde ver).
- `provas/V<n>/`: a prova de cada caso (contagens, prints com dados fictícios). Nunca dado real nem segredo.
- `V<n>-relatorio.md`: as duas rodadas, os erros achados e corrigidos, e os 10 casos sorteados para o dono.

| Rodada | Fase validada | Situação |
| --- | --- | --- |
| V1 | S1 fases 0 e 1 | casos a escrever durante a S1 fase 0 |
| V2 | S1 fase 2 | casos a escrever durante a S1 fase 1 |
| V3 | S2 fase 1 | casos a escrever durante a S2 fase 0 |
| V4 | S1 fase 3 | casos a escrever durante a S1 fase 2 |
| V5 | S2 fase 2 | casos a escrever durante a S2 fase 1 |
| V6 | S3 fases 0 e 1 | só se a S3 abrir |
